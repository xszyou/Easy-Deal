# EasyDeal 已迁移到 GitHub

**新地址：https://github.com/xszyou/Easy-Deal**

EasyDeal 社区版是免费开源的单机桌面客户端：把 AI 接到你本机的 MT5，帮你监控策略执行、解答问题、在异常时提醒你。安装后自带 GMarket v1.082 策略。

源代码、安装包（Releases）、使用教程和问题反馈都已迁到 GitHub，本仓库不再更新。

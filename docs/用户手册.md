## 一、EasyDeal 是什么

一句话：**一个装在 Windows 电脑上、能跟你聊天的 AI 助手，专门帮你管 MT5 上的量化交易。**

它长得像一个聊天软件，你在对话框里用大白话提需求，背后的 AI 能真的帮你动手：

- 帮你**写交易策略（EA）**、编译、调参数
- 把策略**挂到 MT5** 上跑，并实时盯着盈亏
- 给你的 EA **上一层风控保险**（订单护航），盯住它的开仓、平仓、改单，把高风险动作拦下来
- **定时巡查**你的账户，发现风险提醒你

你不需要懂编程。大部分事，**直接在对话框里用人话说就行**。

社区版是免费开源的**单机版**：不需要序列号，交易数据只留在你的电脑上。

## 二、开始之前（先看你的电脑够不够）

| 必须满足 | 说明 |
|---|---|
| **Windows 10 / 11（64 位）** | 只支持 Windows（MT5 本身就只有 Windows 版），Mac / Linux 用不了。 |
| **一个 MT5** | 在券商个人专区下载安装，登录一个券商账号即可。**模拟盘（demo）也行**，建议先用模拟盘练手。还没有账户的，见 README 的「交易账号注册与 MT5 安装」。 |
| **一个 AI 模型** | 已经登录过 Claude Code 的可以直接用；没有的话，「Token」页有火山引擎的购买指引。 |
| **能正常上网** | 5 Mbps 宽带就够，AI 对话需要联网。 |
| **内存建议 8 GB** | 4 GB 也能跑（单个 EA + 偶尔问 AI）。 |
| **建议固态硬盘（SSD）** | 机械硬盘也能用，就是偶尔卡顿。 |

> **关于网络**：用火山引擎、DeepSeek 这类国内模型服务，国内可以直接连，不需要代理。如果用的是 Claude 官方账号或其他国外服务，可能要在「Token」页底部配一个本地代理。

## 三、5 分钟上手（第一次用照着做）

**第 1 步｜下载并安装**
到 [GitHub Releases](https://github.com/xszyou/Easy-Deal/releases) 下载最新的 `EasyDeal-Community-…-x64-setup.exe`，双击跟着向导装完，装完会自动打开。不需要序列号。

**第 2 步｜配好 AI 通道**
打开「**Token**」页，三选一：

- 电脑上已经登录过 Claude Code：用默认的「**系统**」就行。
- 手里有自己的模型 API Key：选「**自定义端点**」，填地址、模型和 Key。
- 都没有：点顶部「**查看火山引擎注册指引**」，按指引开通后，把 Key 填进「自定义端点」。

**第 3 步｜连上你的 MT5**
打开「**MT5**」页，点「**+ 添加实例**」，选择 MT5 的程序目录和数据目录（怎么找数据目录见 5.2）。

**第 4 步｜挂上内置的 GMarket**
打开「**策略**」页，列表里已经有内置的 **GMarket v1.082**。选好 MT5 实例后点「**挂载**」，第一次挂载会弹出风险提示，确认后开始挂载。

**第 5 步｜发第一句话**
回到「**AI**」页，在对话框里随便说点什么，比如：

- 「我现在 MT5 账户有多少钱？」
- 「帮我看看 GMarket 现在运行得怎么样」
- 「帮我写一个简单的金叉死叉 EA」

AI 会一边「思考」一边动手，结果直接显示在对话里。

> 想让 AI 一步步带你配置：「设置」页顶部的「关于」卡片里点「**AI 指引配置**」。

### 延伸｜你的「工作区」在哪、放什么

EasyDeal 会在你电脑上建一个**工作区目录**：你的 EA、分析报告、给 AI 看的资料、对话截图、长期偏好都在这里。最快的打开方式：

> 「**设置**」页 → 拉到最下面的「其他信息」卡 → 点「**打开工作目录**」。

完整路径是 **`%APPDATA%\easydeal-community\workspace`**（粘到 Windows 文件管理器地址栏回车也行）。

| 文件夹 / 文件 | 放什么 |
|---|---|
| `strategies/` | 你**所有的 EA**（`.mq5` 源码 / `.ex5` 编译产物 / `.md` 说明文件），内置的 GMarket 也在这里 |
| `knowledge/` | **塞给 AI 看的资料**：PDF、说明文档、截图，AI 回答时能引用它们 |
| `analysis/` | **分析报告**，想让 AI 分析的 MT5 测试报告（`.htm`、`.xml`）往这放 |
| `screenshots/` | 你在对话里贴的截图自动存这里 |
| `preferences.md` | **你想让 AI 长期记住的偏好**（比如「我只做 H1」「别凌晨开仓」「亏损超 X 一定提醒我」），AI 每次对话都会读它 |

其他以 `.` 开头的隐藏目录、`logs/` 等是系统自动管理的，**不用手动动**。

## 五、核心玩法（手把手）

### 5.1 跟 AI 对话（最常用）

就在「AI」页的对话框里，用**大白话**说你想干什么。AI 不只是聊天，它能真的读取你的 MT5、读写策略文件、编译 EA。

几个能直接说的例子：

- 「帮我写一个 RSI 超买超卖的 EA，黄金，H1 周期」
- 「我 GMarket 这只 EA 现在持仓多少、浮亏多少？」
- 「GMarket 这组单**历史上最大浮亏**到过多少？净值最深回撤多少？」（跑马丁、网格的朋友常用）
- 「每小时帮我看一次账户，浮亏超过 500 就提醒我」

小贴士：

- AI 是**接着上一句聊**的，可以一步步追问、修改。
- 每只 EA 可以开一条**专属会话**：AI 会自动带上这只 EA 的说明、参数、战绩和持仓，一进来就知道在聊哪个策略。
- 复杂的活（比如编译、调参数）可能要等几十秒到几分钟，**正常现象，耐心等**。
- **越用越懂你**：你反复纠正的习惯，它会慢慢记住。

### 5.2 连接 & 管理 MT5

「MT5」页能看到你添加的所有 MT5，每个一张卡片，显示盈亏、点差、是否在运行、关联了哪只 EA。

**添加 MT5**：点「+ 添加实例」，选择 MT5 的**程序目录**和**数据目录**。数据目录这样找：

1. 打开你的 MT5；
2. 菜单「文件 → 打开数据文件夹」（快捷键 `Ctrl+Shift+D`）；
3. 把弹出来的文件夹路径填到 EasyDeal 的「数据目录」里。

配对之后，策略页、护航页才能正确显示这个 MT5 上的 EA 和订单。还没有交易账户的，在添加实例的窗口里切到「**还没有交易账户？**」按步骤开户。

> 有多个 MT5（比如一个跑黄金、一个跑外汇）完全支持，每只 EA 可以分别挂到不同的 MT5 上。

**想让某个 MT5 真正停下来**，请用 EasyDeal 里 MT5 卡片的「**停止**」按钮。EasyDeal 启动时不会自动打开 MT5。

### 5.3 做一个 EA 策略

**🌟 最省心的流程（导入一个现成的 EA）**

> **「策略」页 → 添加文件（选你的 `.mq5` 或 `.ex5`）→ 让 AI 生成策略说明 → 让 AI 生成监控规划 → 挂载**

翻译成大白话：

1. 在「策略」页点「**添加文件**」，选中你已有的策略文件导进来（会**复制**一份，不动你的原文件）；
2. 跟 AI 说「**帮 XXX 生成策略说明**」：AI 读懂这只 EA，写一份中文说明，讲清它怎么开平仓、风险点在哪；
3. 跟 AI 说「**帮 XXX 生成监控规划**」：AI 帮你配一个定时巡查任务（见 5.5），不只盯浮亏，还会**对照这只 EA 本该有的逻辑，判断它有没有跑偏**；
4. 点这只 EA 那行的「**挂载**」，挂到 MT5 上开始跑。

内置的 GMarket 已经带好了策略说明，直接挂载即可。

**完整流程拆解**（想细抠的往下看）

**① 建源码**

- 让 AI 写：对话里说「帮我写一个 XXX 策略的 EA」，写好后「策略」页几秒内会自动出现这只新 EA。
- 自己导入：「策略」页点「添加文件」。

**② 编译**：对话里说「编译 strategies/MyEA.mq5」，AI 会调用 MT5 的编译器生成 `.ex5`。

**③ 挂载**：在这只 EA 那行点「**挂载**」。EasyDeal 会把 EA 挂到图表上，有多个 MT5 时会让你选挂到哪个。

> ⚠️ **自动挂载不总是一次成功**。挂完请到 MT5 图表**右上角**看：出现**这只 EA 的名字和一个「专家」小图标**就说明挂上了，并且要确认 MT5 顶部的「算法交易」按钮是打开的。没挂上就再点一次挂载，或者手动在 MT5 里挂。

挂上之后，这只 EA 那行会显示当前持仓、浮亏、运行时长、交易笔数和累计盈亏。

> **做非黄金品种的朋友注意**：每只 EA 默认认的是黄金（GOLD / XAUUSD 系列）。做外汇、指数、加密的，要在「策略」页这只 EA 那行的「**品种**」格子里改成你券商实际的品种名（MT5 里 `Ctrl+M` 打开「市场报价」，右键「显示全部」能看到真实名字）。改完**新开一条对话**才生效。

**④ 暂时不跑了用「卸载」，彻底不要了用「删除」**

- **🛑 卸载**：把 EA 从 MT5 上卸下来，**保留源码和配置**，随时能再挂载。
- **删除**：一次性清干净，包括策略文件、MT5 里的编译产物、挂载关系和护航绑定。

**⑤ 每只 EA 自带一本「经验笔记」📒**
AI 会为每只 EA 单独记录运作经验：你做过的人工干预、踩过的坑、调参教训、每天的交易小结。下次巡查、挂载这只 EA 之前会**先翻这本笔记**。想看或自己补几条：点这只 EA 那行的「**📒 经验**」。

**⑥ 进阶｜同一策略复制多份、挂不同账户**
用「**📋 复制**」把一只策略复制成多份，每份绑定不同的 MT5、配不同的品种，一套逻辑多账户跑。**每份的魔术号务必设成不同的数**，否则同一账户里的订单归属、统计和护航会混在一起。

### 5.4 订单护航（给 EA 上一层保险）🛡

护航就像给你的 EA 配了个「风控员」，盯住它的每一个**开仓、平仓、改单**。在「护航」页操作。

> ⚠️ **护航目前是实验性功能**，还没经过充分验证。请把它当辅助参考，**别当唯一的风控防线**。

两种模式：

- **监控（只看不拦）**：把每笔单都记下来、算账给你看，但**不挡单**。
- **拦截（真挡单）**：EA 要下高风险单时，护航能直接**拦下来**。

**怎么配（3 步）：**

1. **启用监控（零侵入，立刻能用）**：在「策略」页找一只**正在跑**的 EA，点「**🛡 护航**」→ 填这只 EA 的魔术号（GMarket 默认是 999）→ 启用。「护航」页马上就能看到它。

2. **（可选）升级到拦截，下面两步缺一不可**：
   - **注入代码**：跟 AI 说「**帮 XXX 注入护航拦截代码**」，AI 会改 EA 源码，加上「下单前先问一下护航」的钩子并重新编译。这一步需要 EA 的 `.mq5` 源码，只有 `.ex5` 的 EA（包括内置的 GMarket）只能用监控模式。
   - **在 MT5 里加网址白名单（必须你自己手动做）**：打开 MT5「**工具 → 选项 → EA 交易**」，勾上「**允许 WebRequest 用于以下网址列表**」，把这 3 个网址逐行加进去：`http://127.0.0.1:19527`、`http://127.0.0.1:19527/check`、`http://127.0.0.1`。端口默认 19527；开了多个 MT5，或护航页提示的端口不是 19527，就把提示的端口也加进去。

3. **看效果**：「护航」页顶部是累计审批、拦截和手数调整，中间是每只 EA 的模式，底部「在跑订单」每笔都标了是否在护航中。

护航还会**每天学习**你最近 30 天的成交，发现哪些动作胜率明显偏低，给你可一键应用的调整建议。

**护航管什么：**

| 动作 | 监控模式 | 拦截模式下可以挡 |
|---|---|---|
| **开仓** | ✓ 记录和告警 | ✓ 手数、持仓数、回撤、锁仓等超限 |
| **改单** | ✓ 记录和告警 | ✓ 挡「把止损往亏损方向挪、或删掉止损」（收紧止损、改止盈不受影响） |
| **平仓** | ✓ 记录和告警 | ✓ 挡「过早平掉离止盈还很远的盈利单」（止损平仓永远放行） |

「护航」页每只 EA 那行还有两个开关：**🛡 拦 SL 外扩**默认开；**平仓拦截**默认关，打开时要二次确认。

**消息面护航（审批马丁加仓）**：EA 准备开马丁单前先问护航，护航让 AI 结合金十快讯和经济日历判断是否放行。这项功能默认关闭，要在「护航」页为某只 EA 手动开启，可以选「只记录」或「真挡单」；同样需要 EA 接入护航代码。AI 出错、超时或拿不准时一律放行，最坏情况等同于没开。

### 5.5 定时任务（防爆仓巡查，以及任何要定时重复干的活）

「监控」页是个**通用的定时执行器**，凡是你希望 AI **隔一段时间自动帮你干一次**的事，都能交给它：

- **防爆仓巡查**：每小时查一遍持仓浮亏，超过阈值提醒你；
- **EA 体检**：每天收盘后，让 AI **核对这只 EA 今天是不是在按它该有的逻辑跑**；
- **行情播报**：每天早上把黄金或你关注品种的隔夜行情总结一遍；
- **定期总结**：每周日汇总各 EA 的盈亏、胜率、最大回撤。

**两种建任务的方式：**

1. **让 AI 帮你建（最省事）**：在「AI」页说「**帮我建个定时任务：每天 9 点总结一下黄金行情**」。
2. **自己在「监控」页建**：点「+ 新建任务」，填名字、多久跑一次、让 AI 做什么（用大白话写），还可以绑定一个或多个策略。绑定的策略都停跑时，任务会自动跳过，不浪费模型额度。

存好后它就按点自动跑，可以随时「立即跑一次」测试，或暂停。

> 💡 **AI 监控有多深**：给它这只 EA 的策略说明后，它能**先推断出这只 EA 本该怎么开平仓**，再对照实际持仓，判断它**是不是在按设计逻辑执行**、有没有设计外的异常（比如该止损没止损、突然反向重仓、参数像是被改过）。

> ⚠️ EasyDeal **故意没做**「一键设最大亏损就自动平仓」的全局开关，那样做技术上不可靠，反而容易误事。**定时巡查加上护航挡单**才是更稳的防风险方式。

### 5.6 资讯 / 教程 / 知识库

- **资讯**：金十快讯（关键词命中会提醒你）、经济日历、散户情绪。
- **散户情绪**：各品种散户的多空持仓占比，每 30 分钟更新，常作**反向参考**，AI 分析时也会结合它。
- **教程**：精选的量化、EA、MT5 视频教程。
- **知识库**：把 PDF、截图、说明文档放进工作区的 `knowledge` 文件夹，AI 对话时能引用它们来回答你。客户端自带两份资料，每次启动自动更新：这份**用户手册**，以及**《ML4T 中文导读》**（Stefan Jansen《Machine Learning for Trading》第 3 版的通俗导读，讲回测偏差、过拟合、交易成本、风险管理、实盘监控等量化研究方法）。可以直接问 AI「按 ML4T 导读的思路，帮我检查一下这个策略的回测有没有过拟合」。

## 六、设置怎么调（大部分人不用动）

**AI 通道（在「Token」页）**，三选一：

1. **系统**（默认）：用你电脑上 Claude Code 已登录的账号，不用额外配置。
2. **自定义端点**：用你自己的模型服务，填地址、模型和 Key。支持 Anthropic 协议（DeepSeek、月之暗面等）和 OpenAI 协议（通义、智谱、OpenRouter、火山引擎等）。
3. **Codex**：用电脑上已登录的 Codex CLI（ChatGPT 账号）。

**HTTP 代理（在「Token」页）**：用国内模型服务一般不用配。连国外服务连不上时，切到「手动」并填本地代理地址（比如 `http://127.0.0.1:7890`）。

**MT5（在「设置」页）**：查看和修改 MT5 路径，检查 Python 能否连上 MT5。

**高级开关**：默认 AI **不能**直接帮你平仓、改单和开仓，防止 AI 犯错动你的钱。确实需要的话，在「设置 → 高级」勾选「⚠ 允许 AI 直接平仓 / 改单」或「⚠⚠ 允许 AI 直接开仓」才会放开。

## 七、常见问题速查

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| AI 连不上 / 一直转圈 | 模型没配好，或连国外服务没配代理 | 到「Token」页检查当前模式；自定义端点确认 Key 已保存；连国外服务时配代理 |
| 「自定义端点」提示未填 API_KEY | Key 没保存 | 填好 Key 后点保存；还没有 Key 的，看「购买 Token」卡片的指引 |
| 策略页看不到 MT5 上的 EA | MT5 数据目录没配对 | 「MT5」页按 5.2 的方法配好数据目录 |
| 挂载失败 / 没有编译产物 | 还没编译出 `.ex5` | 让 AI「编译这只 EA」，再挂载 |
| EA 明明在跑却显示「未挂载」 | 最近一段时间没有交易（比如周末休市） | 正常现象，等它真正交易一次 |
| 报「MT5 中不存在品种 GOLD」 | 品种名跟券商对不上 | 在「策略」页改这只 EA 的「品种」，**新开对话**生效 |
| 定时任务老报「超时」 | 交代的活太复杂 | 把任务拆简单一点 |
| 手动双击 terminal64.exe 打开 MT5，账号、图表、EA 全没了 | 进了另一个空白的数据目录（启动方式不同） | 数据没丢。关掉它，在 EasyDeal 的 MT5 卡片里点「启动」 |
| 复制的多份策略订单混在一起 | 魔术号重复了 | 每份设成不同的魔术号（包括 EA 参数里的 magic） |

> **万能诊断**：在 AI 对话里直接说「**帮我排查一下 XXX 问题**」，AI 会自己调用诊断工具帮你看。

## 八、已知的「小脾气」（我们坦白说）

下面这些是我们**已知、暂时没能彻底解决**的点，先跟朋友们交个底：

1. **订单护航是实验性功能，尚未充分验证**：请不要把它当成可靠的最后一道防线，重要风控自己也要盯着。拦截模式需要 EA 源码注入护航代码，并在 MT5 里开网址白名单，否则只能监控记录。
2. **EA 自动挂载不总是一次成功**：挂载后请到 MT5 图表右上角确认 EA 名字和「专家」小图标都出现了，并且算法交易已打开。
3. **AI 会犯错**：它很强，但不是永远对。所以**平仓、改单、开仓这类动钱的操作默认锁着**，需要你手动到「设置 → 高级」打开。请把它当一个很能干、但需要你把关的助手，重要决定自己拍板。
4. **只支持 Windows**：Mac / Linux 暂时用不了。

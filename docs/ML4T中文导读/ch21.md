# 第 21 章　强化学习：让模型学会「怎么做」，而不只是「会怎样」

> **对应原书**：Chapter 21 *Reinforcement Learning*（第 569–595 页）
> **一句话读懂**：监督学习回答「接下来可能发生什么」，强化学习回答「现在该做什么」。在金融里，它最靠谱的用武之地不是找 alpha，而是执行、做市和对冲这类「动作本身就是优化目标」的问题；而从模拟器到实盘的鸿沟，是它最大的障碍。

---

## 先说结论：这章到底想让你记住什么

如果你只有 3 分钟，记住这 6 点就够了：

1. **RL 处理的是「一连串决定 + 结果来得晚」的问题。**价值函数的作用，就是把最后的盈亏分摊回之前每一步。
2. **别指望 RL 直接帮你找 alpha。**市场会变、试错要花真钱、奖励容易被钻空子，三样叠在一起，这条路很难走通。它擅长的是执行、做市、对冲。
3. **问题怎么「写」比用哪个算法重要。**状态、动作、奖励三件事里，奖励最要命：智能体只认你写下的公式，不认你的本意。
4. **算法按动作类型挑**：离散选择用 DQN 一系；连续数量用 actor-critic，求稳选 PPO，数据贵选 SAC / TD3。
5. **原书的实验结论都很收敛**：执行比 TWAP 好一点，做市方向对但没赢过解析解，深度对冲排在两个经典方法中间。没有一项说明 RL 天然更强。
6. **决定成败的是模拟器和实盘的落差**。更逼真的模拟、随机化训练环境、离线学习、严格上线流程，都只能缩小它。

下面逐个展开。

## 21.1 金融中的连续决策

### 预测和行动之间少了什么

传统流程是「先预测，再按预测下单」，两步分开做。问题在于下单本身会改变市场：你的买单把价格推高，你原本的预测就不成立了。静态预测模型看不到这个反馈环，RL 则把它当作问题的一部分：智能体在环境里反复「看一眼、做一步、拿反馈」，学出一套从局面到动作的规则（策略），目标是整段时间的累计收益最大。

这带来三个和监督学习不同的地方：

- **反馈是滞后、打包的。**一次漂亮的平仓背后可能有十几个决定，单看最后一步说明不了什么。RL 用价值函数估计「从这里出发、照现在的打法走下去，总共还能拿多少」，借此把功劳分回每一步。这其实正是交易员关心的多期盈亏视角。
- **一体化优化。**不再先做一个中间预测，再拿它去下单，而是直接奖励最终的财务结果。对收益分布、冲击函数的显式假设少了，但要注意，「无模型」只是说不需要状态转移模型，状态设计、奖励形状、模拟器搭建里照样处处是建模选择。
- **要在「用老办法」和「试新办法」之间取舍。**市场会切换状态，只会重复过去的策略迟早失效；可在金融里，试错不能拿真仓位去试，只能在模拟器、历史数据或严格风控框里进行。

### 为什么重心放在执行而不是 alpha

拿 RL 直接学方向性交易，常见的失败原因有三：学到的规律跨市场状态就失效；为了探索而付出的冲击成本是真金白银、收不回来；拿短窗口夏普当奖励，很容易学成过拟合或「奖励作弊」。所以公开的方向性 RL 演示大多停在概念验证。原书的立场是：找 alpha 交给前面几章的「预测 + 组合 + 风控」流水线；RL 留给奖励能直接量出来的任务，比如执行落差、扣掉库存惩罚后的点差收入、对冲盈亏。

> 💡 **类比**：监督学习像天气预报员，告诉你明天大概率下雨；强化学习像司机，要根据路况一路决定加速、刹车、变道，而且他的驾驶本身也在改变周围车流。

## 21.2 把市场写成马尔可夫决策过程

RL 的标准语言是马尔可夫决策过程（MDP）：状态、动作、转移规律、奖励、折扣五件套。原书反复强调，这几项怎么设定，对结果的影响大于算法本身。

### 状态：弥补「看不全」

MDP 假设「知道现在，就不需要过去」。市场显然不满足：只看最新价格和成交量，看不出趋势、所处状态和盘口结构；而且很多东西根本看不到，比如别人的大单意图、暗池里的流动性、还没发布的新闻。实践上的补救有两种：一是把最近若干期的观测和滚动统计量（波动、平均点差、订单流动量）一起塞进状态；二是用 LSTM / GRU 这类带记忆的网络，让模型自己从历史序列里拼出一个「信念状态」。

状态里通常放三类东西，下面换个角度按「它回答什么问题」来整理：

| 它回答的问题 | 典型特征 | 实操提示 |
|---|---|---|
| 盘面现在怎么样？ | 点差、几档深度、买卖失衡 | 执行和做市里最有用的短期信号 |
| 我自己现在怎么样？ | 持仓 / 库存、浮盈浮亏、离截止还剩多久 | 这些是路径依赖的，不放进去就谈不上风险意识 |
| 现在是什么行情？ | 滚动波动、点差水平、日内时段 | 放进去后策略自动「看天吃饭」，不用另写状态切换逻辑 |

### 动作：选择集的形状决定算法

动作是几个固定选项（买 / 卖 / 不动，或几档报价距离），就适合基于价值的算法；动作是一个数（下多少、挂什么价、权重多少），就要用能直接输出连续值的 actor-critic。仓位上限、单笔上限、参与率上限这些约束，可以通过截断动作、在奖励里扣分或带约束的 MDP 实现，但**熔断和监管限额这类硬约束，不能指望智能体「学会遵守」**，必须写死在系统外层。

### 奖励：整个设计的承重墙

智能体会不折不扣地优化你给的那个数字，所以奖励写成什么样，基本决定了学出来的是什么。几条经验：

- **只用每步盈亏当奖励**最直观，但噪声大，容易把智能体推向高波动打法。
- **加风险调整**（夏普、索提诺、卡玛）能让策略更保守。
- **二次型奖励**（财富增量偏离均值的部分按风险厌恶系数扣分）在相当宽的分布假设下近似等价于最大化均值-方差效用，还能让 Q 函数有解析解，后面的 QLBS 就靠这一点。
- **做市时对投机收益打折、对点差收益不打折**，可以压住智能体追趋势的冲动，训练也更稳。

不同任务的奖励怎么搭，原书有一张对照表；这里换成「最容易写错的地方」来看：

| 任务 | 奖励的核心 | 最常见的写错方式 |
|---|---|---|
| 执行 | 负的执行成本 + 剩余仓位惩罚 | 剩余仓位罚得太轻，智能体拖到最后一刻才卖 |
| 做市 | 点差收入 − 库存平方惩罚 | 不罚库存，智能体变成趋势交易者 |
| 对冲 | 期末盈亏分布的风险度量（方差、CVaR 等） | 只看均值不看尾部，极端情景下亏穿 |
| 配置 | 夏普 / 索提诺或均值-方差效用 | 窗口太短，学到的是噪声 |

### 转移和折扣

市场怎么对你的动作做出反应，是无数参与者博弈的结果，没人写得出公式，所以金融 RL 基本都是无模型的，直接从经验学。折扣因子决定「看多远」，执行和对冲这类需要长远规划的任务，一般取 0.99 以上。

## 21.3 核心算法：从 DQN 到 actor-critic

### 一条递归式撑起所有价值方法

贝尔曼方程说的是：在某个局面做某个动作的价值，等于马上拿到的奖励，加上打过折的「下一个局面里最好选择的价值」。有了这个递归，智能体每走一步就能修正一次估计（时序差分学习），不必等整局打完。早期用表格记这些值，深度 RL 把表格换成神经网络，以应付高维、连续的市场状态。

### 怎么挑算法

与其背一张算法参数表，不如按两个问题来决定：

**第一问：动作是离散的还是连续的？**
- 离散 → DQN。它靠经验回放和目标网络稳住训练，Double / Dueling 变体缓解高估问题。
- 连续 → actor-critic。一个网络出动作（运动员），一个网络打分（教练）。教练的评分比「最终输赢」平滑得多，运动员学得更快。

**第二问：数据便宜还是贵？**
- 历史数据有限、怕训崩 → **PPO**。它限制每次更新的幅度，最不容易翻车，是公认的起点；代价是每轮更新后旧经验作废，费数据。
- 有高保真模拟器、数据随便生成 → **SAC / TD3**。它们能反复利用旧经验，省样本。SAC 额外奖励「保持一定随机性」，探索更充分、策略更抗扰动，适合做市和动态对冲，但调参麻烦；TD3 是对 DDPG 超参敏感问题的修补版。
- 也可以两段式：先在模拟器里用离策略算法预训练，再用在策略算法微调上线。

> 💡 **类比**：在策略学习像只能看自己最新一场比赛录像复盘；离策略学习像把所有历史录像都留着反复看，省素材，但旧录像里的自己和现在不太一样，学起来更难把握。

原书的教学环境比较了 DQN、PPO、A2C：三者学习曲线和持仓习惯差别明显，而且换个随机种子结果就变，所以只能当「学习动态」的诊断图，不能读成排行榜。

### 把风险放进目标

标准 RL 只最大化期望，对波动和尾部不管不顾。三种补法各有取舍：均值-方差最省事，惩罚项直接并入奖励，代价是上涨和下跌一视同仁；CVaR 只盯最差那一截结果，贴近机构风控习惯，但基本离不开深度网络；分布式 RL（QR-DQN、IQN）干脆学整个收益分布，决策时想算什么风险指标都行，换风险偏好不用重训。

### 有模型还是无模型

执行和做市通常无模型。深度对冲是例外：它在某个设定好的随机过程（Heston、SABR 等）生成的情景上训练，换了情景模型就得重训。

## 21.4 应用一：最优交易执行

这是 RL 在金融里离实盘最近的方向。问题本身第 18 章讲过：大单拆小单，卖太快被冲击吃掉，卖太慢被行情漂移拖累，目标是执行落差最小。

**经典解的短板。**Almgren-Chriss 给出一条随风险厌恶变化的最优轨迹，但它假设冲击系数和波动都不变、计划一开始就定死。开盘、收盘、新闻前后流动性剧烈变化时，它没法临场调整，这正是 RL 想补的空。

**RL 的写法。**状态里放剩余数量、剩余时间、近期波动、盘口特征、已付成本；动作是下一笔子单的大小（可以离散成剩余量的几个百分比档位），也可以包括选市价还是限价、挂多激进；奖励是执行成本加上对剩余仓位和拖延的惩罚。罚项稍有偏差，就会学出「分数很高、经济上说不通」的策略，比如开头一单不动、或者在两个极端之间来回摆。

**业界案例。**摩根大通的 LOXM 自 2017 年起用深度 RL 执行股票订单，先欧洲后亚洲和美国，据称成交价优于内部基准。它的职责刻意收得很窄，只管怎么下单、不管买什么，而且跑在原有风控里面。训练细节和独立业绩都没公开，只能说明机构有兴趣，不能当可复现的基准。

**模拟器要过关。**只拿历史价格回放来训练远远不够。检验一个执行模拟器，可以问它五个问题：挂单会不会排队？大单会不会推动价格？时间价格优先有没有？会不会只成交一部分？下单到成交有没有延迟？任何一个答案是「没有」，智能体都可能学会钻这个漏洞（比如默认挂在买一就立刻全成），到实盘就露馅。ABIDES 这类多智能体模拟器里有别的交易者对你的单子做出反应，更接近真实。

**原书实验。**
- 教学环境里，PPO 平均执行落差约 44 bp，TWAP 约 53 bp，Almgren-Chriss 约 52 bp。作者只把它算作「按状态调节节奏能小幅改进」的温和证据，而且换随机种子，策略风格就可能从均匀变成后置。
- 币安永续合约的小时数据上，把资金费率溢价放进状态后，PPO 好于 TWAP 和一个简单的溢价规则：溢价高时卖得多，临近资金费结算的两小时内卖得少。样本太小，不能作为上线依据。

> 🧭 **对你的启发**：加密例子的价值不在 RL，而在「把时间点和状态特征放进下单节奏」这个思路。对外汇 / 黄金 EA，对应的状态就是当前点差、是否临近数据发布、隔夜换仓时点。即使不上 RL，按这些条件调整下单节奏也可能省下执行成本。

## 21.5 应用二：做市

做市商两边挂单赚价差。订单流均衡、价格不动的话，这是门稳当生意；麻烦在于两件事：一是**库存越积越偏**，比如手里压了一千股多头，价格跌 1% 就能抹掉几十笔的价差利润；二是**被知情者收割**，消息灵通的人专挑你没来得及更新的报价成交。所以核心任务是：调报价的宽窄和挂单量，在多赚价差和控制这两类风险之间找平衡。

**经典基准：Avellaneda-Stoikov。**它的关键概念是随库存移动的保留价格。手里偏多时，保留价格往下挪，于是卖价报得更积极、买价报得更保守，引导库存回到中性；价差宽度由波动和风险厌恶决定。缺点是要对订单到达率、波动动态做明确假设，真实订单流却不老实。

**RL 的写法。**状态最关键的是库存，其次是盘口、近期波动和动量、时段、成交率和被逆向选择的迹象；动作是买卖两侧各离中间价多远，也可以决定挂多少、行情不对时干脆撤单；奖励是价差收入减去库存平方惩罚，系数越大越在意库存中性。高频场景里延迟是头等大事：报价值多少，不只看价格，也看多快能送到交易所，所以要把挂单时长和下单时机编码进去。

**原书实验：方向对，但没赢。**训练 30 万步后，PPO 的平均清算财富和保留价格基准差不多，但波动大得多，期末库存也略多。单看一条路径，它确实会逆着库存移动报价中心，和保留价格的逻辑一致；可按库存分组统计，报价偏移很小、和库存的关系弱而杂乱，谈不上干净的单调关系。作者的结论是：展示了自适应报价，没有证明能稳定胜过一个设定合理的解析基准。

## 21.6 应用三：衍生品深度对冲

**为什么经典方法不够。**Delta 对冲要完美复制期权，得同时满足连续调仓、零成本、波动率设对三个前提，现实里一个都不成立。有成本就不可能连续调，离散调就会累积误差，常数波动假设让希腊字母系统性偏离。在真实摩擦下，离散 delta 对冲可以证明不是最优。

**深度对冲换了个目标。**它不再追求逐条路径精确复制，而是问：扣除成本后，怎样调仓能让期末盈亏的风险（方差、CVaR 或均值-方差）最小？用神经网络把「标的价格、剩余期限、当前头寸、波动特征」映射成下一期的对冲比例，在情景生成器上端到端训练。和一般 RL 不同，它通常没有逐步奖励，只看期末盈亏分布；关心尾部时，CVaR 是自然的选择。

**不交易区间。**考虑成本的对冲策略往往会学出一条「容忍带」：当前头寸离理想值不远就不动，只有调仓降低的风险值得那笔手续费时才出手。经典的 Whalley-Wilmott 渐近解只能在小比例成本等强假设下推出这种区间，学习方法的好处是能推广到更复杂的动态和产品。

> 💡 **类比**：不交易区间像空调的温控回差。设 26 度，并不是 26.1 度就开机、25.9 度就停机，而是在一个范围内不动作，否则频繁启停的电费（交易成本）比那点温差更贵。

**QLBS：另一条路。**它用 Q-learning 做对冲，靠二次型奖励让 Q 函数可解析求解。两种方法的差别，用一句话说：深度对冲直接学「怎么调仓」，价格是外部给定的；QLBS 先学「每种调法值多少」再推出调法，期权价格作为最优对冲成本的副产品自己冒出来。前者奖励形式灵活但离不开神经网络，后者限于均值-方差、简单情形能算出闭式解。

**原书实验：有竞争力，但不占优。**欧式看涨期权、比例成本、Heston 型情景、所有方法同一套自融资记账：**离散 delta 对冲的离散度和 5% CVaR 反而最好**；深度对冲胜过表格版 Q-learning，在风险指标上介于 delta 对冲和 Whalley-Wilmott 之间。真正的教训是公平比较的三个前提：统一记账、考虑摩擦的基准、目标函数和报告指标一致。问题越偏离 Black-Scholes 的理想世界（动态更复杂、摩擦更大、关注尾部），深度对冲才越有用武之地。

## 21.7 逆强化学习：从行为反推目标

前面三个应用的奖励都是人定的。逆强化学习（IRL）反过来：看着一个执行算法有时激进、波动一大就放慢、不同时段节奏不同，能不能猜出它在优化什么？

**主要做法。**最大熵 IRL 在「让观察到的行为最有可能出现」的同时，对没见过的行为不做多余假设，以此应对多解问题；GAIL 让一个策略去骗过区分真假轨迹的判别器，AIRL 在此基础上把奖励函数显式提取出来，方便迁移。

**为什么不直接模仿。**最省事的办法是行为克隆，把「状态 → 专家动作」当监督学习。它的毛病可以用学开车来理解：只模仿教练的手脚动作，一旦偏离到教练没开过的路段就不知所措，错误越滚越大；路况规则变了（好比交易成本变了）就得重新跟车学；教练的坏习惯也照单全收。IRL 学的是「教练想达到什么」，换了环境可以重新求解；像 T-REX 这样从排序示范中学习的方法，甚至可能学出比任何单个示范者更好的目标。

**在金融里的用途。**从高频订单流反推算法目标、把交易者聚成动量 / 均值回归 / 库存管理等类型；在财富管理里从客户的实际选择推断其真实偏好；用流匹配直接从历史数据模仿做市行为。

**门槛。**示范质量差，推出的奖励就不可靠；奖励用什么特征表达，限定了能推出什么目标（线性形式会漏掉微观结构里的非线性偏好）；最大熵 IRL 内层每次都要解一个完整的 RL 问题，算力开销大。原书用 TWAP 示范做的演示，推出的权重只能定性看，动作分布接近专家也只是行为层面的合理性检查。总之，IRL 回答「该优化什么」，RL 负责「去优化」。

## 21.8 模拟到现实的鸿沟

不管奖励是设计的还是推出来的，最后都要过同一关：模拟器里的好成绩到实盘能不能保住。而且已发表的结果数据、成本模型、执行假设各不相同，彼此很难比较。

### 按「怎么出问题 / 怎么察觉 / 怎么应对」来看

| 怎么出问题 | 怎么察觉 | 怎么应对 |
|---|---|---|
| 市场换了状态，学到的规律过期 | 不同时期样本外表现差异大 | 跨状态验证；按状态切换频率定期重训 |
| 低信噪比 + 大网络 = 记住噪声 | 训练集好、验证集差 | 简化状态、限制容量、离线策略评估 |
| 自己的单子推动价格，别人还会反应 | 实际滑点远高于模拟 | 多智能体模拟器、显式冲击模型 |
| 延迟和成交摩擦 | 实盘成交价系统性偏差 | 把延迟、排队、部分成交写进模拟 |

### 三类缓解手段

- **更逼真的模拟**：让其他参与者会拉宽点差、跟风、撤单，智能体在训练时就经历反身性冲击。
- **环境随机化**：每个回合随机改冲击系数、延迟、点差、费率。与其追求一个「正确」的环境，不如让策略在一片合理的条件里都站得住。
- **离线 RL**：只用历史数据学。难点是历史数据由旧策略产生，新策略想做的动作可能根本没在数据里出现过，所以要么惩罚这些「没见过的动作」，要么把学习限制在数据充分覆盖的范围。决策 Transformer 把它变成序列建模：给定一个目标回报，生成历史上与该回报水平相伴的动作。

### RL 特有的回测坑

除了通常的未来函数、幸存者偏差，RL 还有自己的四个坑：状态里混进了当时拿不到的信息（日内策略用到当天收盘价）；奖励作弊（亏损有罚，智能体干脆不交易）；训练时没有冲击，于是敢下任意大的单；以为限价单一挂就按报价全成。

> 🧭 **对你的启发**：第一个和最后一个坑在 MT5 回测里同样常见：用当根 K 线收完才知道的信息做当根内的决定，以及挂单一触价就默认全额成交。tick 级回测加真实点差、滑点建模，堵的就是这两个洞。

### 冲击把纸面赢家变成输家

原书用一组对比收尾：同一个动量策略、同一笔 500 万美元，放到 2010–2016 年日成交量相差五个数量级的美股上。对超大盘股，这笔单只占日成交量 1.5% 左右，最强冲击假设下照样盈利；对微盘股，它是日成交量的好几倍，纸面大赚变成几乎全亏。在纸面盈利的样本里，订单超过一天成交量的那些，强冲击假设下几乎全部翻成亏损，流动性好的大多活了下来。这就是小盘 alpha 放不大的原因。

### 上线顺序

原书给了四阶段流程，压缩成一条路线就是：**先证明**（跨状态样本外测试、带冲击的模拟、离线策略评估、独立审查）→ **小步走**（模拟盘，再小资金加严格仓位和亏损上限，事先写好放行 / 叫停的量化标准）→ **随时能拉闸**（智能体改不了的硬限额、交易台手动熔断、持续对比实际滑点和延迟与模拟假设、有权叫停的人）→ **长期看护**（定期重训、业绩衰减报警、完整的版本记录以备审计）。

### 可解释性与监管

深度 RL 是黑箱，而欧盟 MiFID II 对算法交易系统的韧性、测试、控制、监控有明确要求。能做的是部分透明：对状态到动作的映射做 SHAP 分析、用决策树近似策略、做反事实轨迹分析。

## 本章小结

- RL 在金融里最有说服力的地方，是动作本身就是优化对象的任务：执行、做市、对冲，因为奖励能对上可观测的经济目标。
- 写成 MDP 时，状态设计、动作约束、奖励工程比算法更关键；硬性风控必须写在智能体外面。
- 算法按动作类型和数据成本选：离散用 DQN，连续用 actor-critic，求稳 PPO、省样本 SAC / TD3；关心风险就用均值-方差、CVaR 或分布式 RL。
- 书中实验都很克制：执行略好于 TWAP，做市方向对但没胜过解析基准，深度对冲排在 delta 对冲和 Whalley-Wilmott 之间。
- IRL 从行为反推目标，比行为克隆更能迁移，但同样受模型假设和数据质量限制。
- 真正的瓶颈是模拟到实盘的落差。基准怎么选、记账是否一致，决定一个 RL 结果只是演示还是站得住脚。
